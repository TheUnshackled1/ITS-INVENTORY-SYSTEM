# 💬 Getting Support

> Official support channels and troubleshooting resources for the **ITS Inventory Management System**.

---

## 📋 Where to Get Help

If you encounter issues, have questions, or need assistance operating the system, please consult the resources below in order:

### 1. 📖 Self-Service Documentation
Before opening an issue or contacting support, check the detailed system documentation:
- **[INSTRUCTIONS.md](INSTRUCTIONS.md)** — Step-by-step setup, database configuration, email OTP settings, and troubleshooting guide.
- **[README.md](README.md)** — Full system overview, system architecture diagrams, features, and API endpoints table.

### 2. 🛡️ Security Vulnerabilities
If you discover a potential security vulnerability or auth issue, please **do not open a public issue**. Follow the private reporting guidelines in our **[SECURITY.md](SECURITY.md)** policy or email `jtcoronel.chmsu@gmail.com` directly.

### 3. 🏢 Institutional Support Channels
For internal ICT and MIS department inquiries within the institution:
- **Management Information Systems (MIS) Department**: Primary department responsible for system operations and user access.
- **Information and Communications Technology (ICT) Department**: Original development team and system turnover leads.
- **Email Contact**: `jtcoronel.chmsu@gmail.com`

---

## 🐛 Submitting a Bug Report or Feature Request

If you have confirmed a bug or have a suggestion for a new feature:

1. **Search Existing Issues**: Check the [GitHub Issue Tracker](https://github.com/TheUnshackled1/ITS-INVENTORY-SYSTEM/issues) to ensure your issue hasn't already been reported.
2. **Open a New Issue**: Click **New Issue** and include:
   - Clear, descriptive title.
   - Expected vs actual behavior.
   - Screenshots or error tracebacks (if applicable).
   - Operating system, Python version, and browser used.

Thank you for maintaining a reliable equipment tracking environment!
